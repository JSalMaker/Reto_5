## Reto de módulos y paquetes 

---

El Reto de organizar un ejercicio en paquetes y módulos está hecho y se puede encontrar con la carpeta de files en la parte de arriba, este contara con dos maneras de organizar los paquetes y los módulos esta es un paquete con un solo modulo, la otra es un paquete con varios módulos, la diferencia de estos es como se importan en el main final y como se relacionan estos entre sí en cada archivo, por ejemplo en el paquete con un solo modulo no hay que estar llamando otros módulos porque ya todas esas clases se encuentran en ese mismo modulo, sin embargo cuando son varios módulos, si hereda conforma etc. una clase de un módulo diferente a otra clase en otro modulo diferente, este tendrá que importarlo en el módulo en el cual pueda hacer la herencia y la conformación.
